# Trace

Android-дневник состояния: настроение, симптомы, сон, препараты, триггеры, календарь и отчёты.  
Интерфейс на русском. Данные хранятся **на устройстве** (offline-first).

> **Это не диагностика и не замена врачу.**  
> Trace не ставит диагнозы, не назначает и не меняет лекарства.  
> Статистика и «прогноз» — наблюдаемые паттерны по вашим записям, а не медицинское заключение.  
> При ухудшении или суицидальных мыслях обратитесь к специалисту / экстренной помощи.

---

## Возможности

| Раздел | Что делает |
|--------|------------|
| **Сегодня** | Ежедневные шкалы, чек-ины, симптомы, триггеры, сон, препараты, заметки |
| **Календарь** | Обзор дней, сводка по записи, личный значок на выбранный день |
| **Отчёты** | Графики и экспорт (JSON / HTML / CSV / PDF) |
| **Прогноз** | Сводка по истории с возможностью поделиться |
| **Упражнения** | Техники самопомощи (по желанию отключаются в настройках) |
| **Настройки** | Каталоги, шкалы, импорт данных, напоминания, оформление |

Технически: Kotlin, Jetpack Compose, Room, Hilt, WorkManager, Health Connect.  
`minSdk 30` · `targetSdk 35` · `applicationId`: `com.moodlife.app`

## Быстрый старт

1. Установите [Android Studio](https://developer.android.com/studio) и **JDK 17 или 21** (не 25).
2. **Файл → Открыть** → папка **`android/`** (не корень репозитория).
3. Дождитесь Gradle Sync.  
   Если ошибка *Incompatible Gradle JVM* → **Настройки → Сборка → Gradle → Gradle JDK → 17/21**.
4. Запуск: ▶ Run на эмуляторе или телефоне.

### Сборка из терминала

```powershell
cd android
.\gradlew.bat assembleDebug
.\gradlew.bat test
```

Подписанный APK для раздачи друзьям — см. **[GITHUB_APK.md](GITHUB_APK.md)**.

## Что не коммитить

В `.gitignore` уже исключено:

- `local.properties` (путь к SDK)
- `keystore.properties`, `*.keystore` / `*.jks` (подпись release)
- `build/`, `.gradle/`, `*.apk`, `*.hprof`

Перед `git push` проверьте, что секреты не попали в индекс:

```powershell
git status
# не должно быть: keystore.properties, release.keystore, local.properties, *.apk
```

## Медицинская этика

- Пользовательские записи (настроение, симптомы, журнал, сон, лекарства) — чувствительные данные.
- Облачный бэкап / экспорт — только по явному действию пользователя.
- Контент упражнений и источников — опорные формулировки самопомощи, не клинические рекомендации.
