## Важно (прочитайте)

> **Trace — инструмент самонаблюдения, а не медицинское изделие и не диагностическая система.**

| Trace **делает** | Trace **не** делает |
|:---|:---|
| Помогает вести дневник (настроение, симптомы, сон, препараты, триггеры) | **Не** ставит диагнозы (БАР, депрессия, мания и любые другие) |
| Показывает статистику и паттерны по **вашим** записям | **Не** заменяет врача, психотерапию или экстренную помощь |
| Даёт техники самопомощи и напоминания | **Не** советует начинать, менять или отменять лекарства |
| Хранит данные локально (Room) на устройстве | **Не** публикует записи без вашего явного действия |
| Даёт «прогноз» как обзор по вашей истории | **Не** предсказывает болезнь и не выдаёт клинический вердикт |
| Показывает цитаты и источники к текстам/шкалам | **Не** превращает цитату в персональную медрекомендацию |

При ухудшении состояния, суицидальных мыслях или ощущении опасности — к специалисту или в службу экстренной помощи. **Кризисный план** в приложении — ваш список контактов, не замена вызова помощи.

## Первый запуск

Раздел для тех, кто открыл Trace **впервые**. Коротко: *что это*, *как пользоваться*, *зачем заполнять*, *почему так устроено*.

### Что это за приложение

**Trace** — личный дневник состояния. Вы отмечаете, как чувствовали себя в конкретный день (спад / подъём / тревога / раздражение и другое). Приложение **сохраняет** отметки локально и показывает:

- календарь по дням;
- графики и отчёты;
- краткий «прогноз» по **вашей** истории;
- упражнения самопомощи и цитаты из литературы.

Цель — **видеть динамику** и спокойнее обсуждать её с врачом, а не «получить диагноз от телефона».

### Зачем заполнять экран «Сегодня»

Экран **Сегодня** — главный. Один день = одна картина состояния.

1. Откройте вкладку **Сегодня**.
2. Пройдитесь по **шторкам** (оси настроения, сон, симптомы, триггеры, препараты…).
3. Дождитесь автосохранения осей или нажмите **Сохранить**, если кнопка на экране есть — данные также сбрасываются на диск при уходе с экрана.

Можно заполнять **не всё сразу**: даже 3–4 основные оси уже полезны. Чем регулярнее записи, тем осмысленнее календарь, отчёты и прогноз.

### Что означают шкалы

Чаще всего шкала **0–5** (смысл условный, подписи можно настроить):

| Балл | Смысл |
|------|--------|
| **0** | нет / не заметно |
| **1–2** | слабо / чуть заметно |
| **3** | мешает повседневности |
| **4–5** | сильно / «срыв» |

Есть и другие типы: да/нет, качественные 4 ступени, 0–10. Числа — **ваши** оценки, не лабораторный результат.

### Почему так много шторок

Каждая шторка — отдельная тема дня. Карандаш у заголовка ведёт в **соответствующий раздел настроек** (полный редактор каталогов и шкал).

Лишнее можно **скрыть или переставить**: **Настройки → Экран «Сегодня»**.

### Чек-лист первого дня

Сделайте по порядку:

- [ ] **Настройки → Оформление** — светлая/тёмная тема, стиль интерфейса.
- [ ] **Настройки → Симптомы / Триггеры / Продромы** — «подставить базовый набор» (потом правите под себя).
- [ ] **Настройки → Препараты** — если принимаете лекарства: названия и время приёма.
- [ ] **Настройки → Кризисный план** — контакты / куда звонить.
- [ ] **Настройки → Другие настройки** — напоминания о дневнике и приёме; вкладка **Упражнения** (вкл/выкл).
- [ ] Вернитесь на **Сегодня**, заполните день (хотя бы оси) и убедитесь, что данные сохранились.
- [ ] Откройте **Календарь** — день должен отметиться цветом/значками.

**По желанию позже:**

| Опция | Зачем |
|--------|--------|
| **Цикл** | Фазы менструального цикла на календаре / в контексте |
| **Погода / город** | Контекст дня (нужен интернет для обновления) |
| **Импорт / Health Connect** | Сон, шаги и др. из других приложений (где доступно) |
| **Упражнения** | Вкладка самопомощи (можно скрыть) |
| **Цитаты** | Источники формулировок и шкал |

### Почему прогноз сначала «пустой»

Прогнозу нужна **история**. После нескольких дней записей появится сводка. Это **не** предсказание болезни, а обзор по вашим же данным.

### Как делиться с врачом

**Отчёты → экспорт**:

| Формат | Назначение |
|--------|------------|
| **JSON** | Полный архив / бэкап (`Trace-backup-…`) |
| **HTML / PDF** | Удобно показать врачу (`Trace-report-…`) |
| **CSV** | Таблица для таблиц / анализа |

Экспорт и «поделиться» — **только** когда вы сами нажали кнопку.

### Почему данные «не в облаке по умолчанию»

Дневник настроения и симптомов — чувствительные данные. Trace пишет их **сначала в локальную базу** на телефоне и работает **без интернета**. Сеть нужна лишь для погоды и части импорта. Так безопаснее и надёжнее при сбоях сети.

## Возможности по вкладкам

### 📅 Сегодня

Главный экран ежедневной записи.

- **Основные оси** настроения (подавленность, подъём, тревога, раздражение) и **дополнительные** шкалы (силы, внимание, аппетит, общение и др.)
- **Клинические / режимные** поля: качество сна, часы сна, время «легли / встали», функционирование, безопасность, режим, алкоголь / ПАВ (как самоотчёт)
- **Чек-ины** в течение дня (утро / день / вечер или своя схема и набор осей)
- **Контекст дня**: погода, фазы луны, цикл (если настроено)
- **Сон**: ручной ввод; возможен prefill из Health Connect / внешних данных
- **Препараты**: слоты приёма и отметки «принято»
- **Симптомы**: каталог с цветами и разными типами шкал; быстрый отклик UI
- **Триггеры / факторы**: отметка → интенсивность
- **Продромы** (ранние признаки): ручные отметки + подсказки по отмеченным симптомам (не диагноз)
- **Заметки дня** с временем
- **Порядок и состав шторок** настраиваются
- Баннеры-предупреждения по паттернам самоотчёта + чип **кризисного плана**
- Сохранение: локальная БД; оси и правки сбрасываются на диск при уходе с экрана / смене дня

### 🗓️ Календарь

- Месячная сетка с цветом / интенсивностью по состоянию дня
- Иконки погоды, луны, цикла; **личные значки** на дни, которые вы отметили сами
- Нажатие на день → краткая **шторка-сводка** и переход в «Сегодня» на эту дату
- Настройки цикла (длина, последняя менструация, нерегулярность)

### 📊 Отчёты

- Выбор месяца, линейные и другие графики (настроение, сон, энергия, режим, safety и т.д.)
- Настраиваемая **видимость** графиков
- Блок **«Ваши паттерны»** (exploratory, по достаточности истории)
- Экспорт **JSON / HTML / CSV / PDF** с именами `Trace-report-*` / `Trace-backup-*`

### 🔮 Прогноз

- Сводка на **7 дней** по истории записей (+ цикл, если задан)
- Символы и краткие пометки; кнопка **«поделиться»**
- При малой истории — честное «мало данных», без выдуманной точности

### 🧘 Упражнения

- Практики самопомощи (режим, дыхание, активация и др.) с опорой на литературу
- Вкладку можно **скрыть** в настройках
- Это не замена терапии и не назначение лечения

### ⚙️ Настройки

| Раздел | Что внутри |
|--------|------------|
| Симптомы / Триггеры / Продромы | Каталоги, цвета, шкалы, базовые наборы |
| Препараты | Список, дозировки, время, связанные напоминания |
| Экран «Сегодня» | Порядок шторок, чек-ины, trackables |
| Кризисный план | Контакты и заметки «куда звонить» |
| Цикл | Параметры менструального цикла |
| Погода | Город / источник прогноза |
| Импорт данных | Health Connect, файлы, совместимый импорт |
| Оформление | Тема и визуальный стиль |
| Данные | Бэкап / восстановление JSON |
| Другие | Напоминания, вкладка упражнений и пр. |
| Цитаты / источники | Библиотека формулировок и ссылок |

### 📚 Цитаты

Экран источников и цитат к шкалам / текстам самопомощи (маршрут `sources`, подпись вкладки **Цитаты**).

- Список источников по категориям (литература, гайды и др.)
- Фокус на конкретной цитате (например, переход со шкалы / карточки)
- Номера / метки цитат для удобной ссылки в UI
- Дисклеймер на экране: цитата — **справочный** материал, не индивидуальная медрекомендация
- Открывается из навигации к источникам и из цитат у элементов UI (не обязательно как постоянная кнопка нижней панели)

Цель раздела — явно отделить **литературу** от **ваших** отметок и статистики.

| Параметр | Значение |

## Технологии и особенности

- **Kotlin**, Jetpack **Compose**, Material 3
- **Room** — локальная БД, **источник истины**; миграции **без** уничтожения данных пользователя
- **Hilt**, Coroutines / Flow, ViewModel, Repository
- Напоминания через AlarmManager / связанные компоненты
- **Health Connect** — чтение сна/активности там, где доступно
- **Offline-first**: сначала запись локально, сеть не обязательна для ядра
- Чувствительные тексты дневника **не** логируются в открытом виде
- UI на русском; экспорт с префиксами **Trace-**

## Что не коммитить

Не добавляйте в git и не кладите в публичные архивы:

| Запрещено | Почему |
|-----------|--------|
| `local.properties` | Локальный путь к Android SDK |
| `keystore.properties` | Пароли подписи |
| `*.keystore` / `*.jks` | Приватные ключи |
| `*.apk` / `*.aab` | Бинарники (раздавайте отдельно) |
| `build/` , `.gradle/` , `.kotlin/` | Артефакты сборки |
| `.idea/` | Локальные настройки IDE |
| `.cursor/` , `.sync-diffs/` , `.git/` | Служебные папки |
| `*.hprof` | Дампы памяти JVM |
| `google-services.json`, токены, API-ключи | Секреты |

См. корневой `.gitignore` и [GITHUB_APK.md](GITHUB_APK.md).

## Сборка и запуск

```text
moodlife-android-github/
├── README.md                 ← вы здесь
├── LICENSE                   ← MIT
├── .gitignore
├── GITHUB_APK.md             ← подпись и раздача APK

```

1. **Файл → Открыть** → папка `android/`
2. Gradle Sync с **JDK 17 или 21**
3. ▶ Run (телефон или эмулятор x86_64)

```powershell
cd android
$env:JAVA_HOME = "C:\Program Files\Microsoft\jdk-21.0.12.101-hotspot"  # свой JDK 17/21
.\gradlew.bat assembleDebug
.\gradlew.bat test
```

Release / подпись / раздача APK: **[GITHUB_APK.md](GITHUB_APK.md)**.

> Если установка на эмулятор падает с `INSTALL_FAILED_NO_MATCHING_ABIS` — нужна **debug**-сборка (в ней есть `x86_64`). Release только для реальных ARM-телефонов.
