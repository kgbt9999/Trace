# Changelog

Все заметные изменения Trace. Формат близок к [Keep a Changelog](https://keepachangelog.com/).
Версии: `versionName` / `versionCode` в `android/app/build.gradle.kts`.

## [0.3.0] — 2026-09-23

### Добавлено
- Клинический **отчёт для врача** (HTML + PDF): KPI, наблюдательная оценка, полярность −5…+5, сон+настроение, радар, теплокарта, триггеры/ранние признаки, лекарства, история по шкалам, кризисный план из настроек.
- Отдельный **пациентский HTML**-обзор месяца.
- **Лабораторные показатели** и **измерения тела** (локальный ввод) на экране физического состояния; учёт в бэкапе.
- Онбординг / стартовые подсказки, empty states.
- В отчётах: настраиваемые графики, **fullscreen по нажатию**, график полярности и связанные диаграммы.
- Сводная **таблица истории по шкалам** дневника (не типы эпизодов / не диагноз).

### Изменено
- Вёрстка и читаемость **PDF** для врача (сетка, переносы, секции, футер).
- Экспорт: префиксы `Trace-doctor-*` / `Trace-patient-*`; формулировки строго наблюдательные.
- README и описание возможностей под 0.3.0.

### Безопасность / данные
- Локальная БД остаётся **offline-first**; чувствительный контент не логируется.
- Миграции Room для новых сущностей health-tracking **без** wipe пользовательских данных.

### Важно
Trace — инструмент самонаблюдения. Отчёты и графики **не** ставят диагноз и **не** советуют менять терапию.

## [0.2.0] — ранее

- Шифрование Room (SQLCipher), hardening манифеста.
- Кризисный план в верхней панели, календарь без лекарств в ячейках, dual export (данные vs отчёт).
- Сводки физического состояния в календаре, weekly backup, упражнения.
- Исправления свайпа дней на «Сегодня», синхронизации подписей, графика доз.

## [0.1.0] — scaffold

- Первичный Android-каркас Trace: Сегодня, календарь, отчёты, прогноз, настройки, offline Room.
